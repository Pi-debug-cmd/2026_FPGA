# 02 算法链选型：三个"看起来成立"的前提，两个被实测否决

日期：2026-10-24 ~ 2026-10-25
相关：`board_c_20261025_stage2.md` §2.2、`board_c_20261025_squeeze.md` §2、`scripts/stft_env_20261024.py`

## 1. 这一轮要解决什么

把电脑端"目标音色迁移"的算法链压到 Zynq-7020 的双核 A9 上跑：
**WORLD 分析 → 513 bin 对数谱 → 32 阶 DCT 倒谱 → 646 维特征 → 4×512 MLP → 48 阶倒谱残差
→ 包络移植 → ISTFT**。目标 RTF ≤ 1.0，且不换模型输入分布（否则等于重训）。

## 2. 提示词要点

> "按批准的优化顺序做：① D4C 每 N 帧一次 + 插值；② CheapTrick 只跑一遍；③ MLP int8；
> ④ 必要时双核。**每一项都要给出与精确版的波形相关和 UTMOS 变化**；
> 任何一项达不到门限（相关 ≥0.99、UTMOS 降 ≤0.05）就退回去换方案，不要硬上。"

关键要求：**每项优化必须自带"可被否决"的门限**。这一句直接决定了后面的走向。

## 3. 模型的关键决策

| 决策 | 依据 | 结果 |
|---|---|---|
| D4C 改成"每 10 帧算一次 + 帧间线性插值" | D4C 的帧网格是入参，跳过的计算是真的跳过 | 板上 1470 → 155 ms，波形相关 0.99975，UTMOS −0.0018 `[实测]` |
| 第二遍 WORLD 不再跑 DIO/StoneMask，改为 `f0_shifted = 1.4 × f0_source` | 升调是按比例的，重估 f0 只是引入噪声 | 省约 220 ms，相关 0.9986 `[实测]` |
| 把第二遍 WORLD 放到 worker 线程与 MLP 并行 | 第二遍只依赖 `xB`，与 MLP 无数据依赖 | 900 ms 几乎完全被隐藏 `[实测]` |
| 不换 fft_size 1024 → 512 | 512 点只有 257 bin，而模型输入是 513 bin，等于换输入维度 | 结构上不可行，跳过（不是没时间）`[推断]` |

## 4. 被证伪的假设与纠正过程（本节是重点）

### 4.1 "CheapTrick 只跑一遍，用频轴映射 `logsp_b[b] = logsp_src[b/1.4]` 就够了"

- **当时判断**：升调 = 频率轴 ×1.4，那么包络也应该是频率轴 ×1.4，直接重采样即可，
  这样第二遍 CheapTrick 完全省掉。
- **实验**：与"精确两遍"版比波形相关。
- **结果**：**0.9793**，低于门限 0.99 → **否决** `[实测]`。
- **为什么前提不成立**（实测拆解）：SoundTouch 的升调 = 重采样（频轴 ×1.4）**再** WSOLA
  时长拉伸；重采样的抗混叠滤波会把 5.7 kHz 以上搬移后的内容切掉，
  同时 CheapTrick 的 F0 自适应窗长在 WSOLA 后的信号上给出不同的平滑。
  所以真实包络不是源包络的简单拉伸，形状差约 2%（中位 3.7 dB）。
- **纠正**：改用 `f0 继承 + 精确 CheapTrick`，并把第二遍藏到 MLP 后面 → **0.9986**，达标。

### 4.2 "用 STFT 幅度谱 + DCT-48 当包络，比 CheapTrick 便宜得多"

- **结果**：相关 **0.8857**，比 4.1 更差 → 直接弃 `[实测]`。
- **原因**：模型是在 WORLD 包络上训练的（`synth_eval.analyse()` 调 WORLD），
  裸 STFT 幅度谱属于分布外输入。

### 4.3 "隔 2 帧跑 CheapTrick + 插值也能过 0.99"

- **结果**：**0.9893**，差 0.0007 → 否决 `[实测]`。
- 这条最能说明"门限要提前定死"：如果门限是 0.98，这个方案就会被采纳，
  然后在听感上留下一个说不清的问题。

### 4.4 "CheapTrick 隔帧可以一路隔到 3 帧"

- **结果**：`--ct-stride 3` 波形相关 **0.9932** < 0.995（补充轮的门限）→ 否决 `[实测]`。
- `--ct-stride 2` 通过（0.9968），但代价明确：identity −0.032、CER 0.0769 → 0.1538
  （4 s 只有约 13 个字，absolute 差 1 个字就翻倍）。因此它只作为**演示档开关**，
  不作默认。

## 5. 沉淀

1. **"结构上等价"的假设最容易错**：频轴映射在数学上"应该"成立，实测差 2%。
   凡是"应该等价"的化简，都必须先跑一次相关，再决定要不要写进代码。
2. **门限先写、后做**：0.99/0.995 这两个数字是事先写进任务书的，
   否则 0.9893 这种结果会被"差不多"放过。
3. **被否决的方案要留在代码里**（`--ct-once`/`--ct-stft` 保留为对照开关），
   这样下一个人不必重新试一遍。
4. **省时间的顺序**：先做"结构上真的跳过计算"的（D4C 隔帧），
   再做"藏到并行线程"的（第二遍 WORLD），最后才动"近似"（频轴映射）——
   前两类没有质量代价，第三类一定有。
