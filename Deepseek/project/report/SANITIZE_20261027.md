- 对象：参赛包 `competition_pkg_20261026/`（**341 个文件 / 48.7 MiB**，58 个目录；不含本记录，含本记录 342 个）
- 时间：2026-10-27（Asia/Shanghai）
- 依据：提交门户要求「技术文档不得包含指导老师姓名、学校名称等与作品无关的信息」
- 边界：**只改包装材料（文档/说明/示例 JSON）**；实验产物（`metrics/logs/`、位流、blob、WAV、证据图）不动
- 结论：**身份类信息 0 项**（学校/教师/队员/学号/邮箱/手机号/用户目录名全部为空）；`<workspace>` 占位化 21 处、称谓泛化 7 处，共 **28 处替换、14 个文件**

## 0. 一句话结论

这份包**本来就没有**学校名、教师名、队员真实姓名、学号、邮箱、手机号、GitHub 实名
（逐类扫描均为 0 命中，见 §2）；真正需要处理的是两类**弱识别信息**：

1. **本机绝对路径**里带出的个人工作目录名（`D:\<research-dir>`、`D:/<tool-dir>`）——21 处，已占位化为 `<workspace>` / `<tools>`；
2. **"队友 / 写作者"这类指向具体个人的称谓**——7 处，已泛化为"对照支线 / 三方"。

同时把 24 处**原始日志里**的同类路径**有意保留**（理由见 §5），并给出可选的脱敏命令。
