## 作品简介

本作品是一款支持现场录入目标声音的实时变声器，可将单人输入语音向录入的目标声线转换，同时保持讲话内容清晰可懂。系统支持目标声音录入、实时声线转换及原声与转换效果对比，后期可扩展多目标声音保存与切换功能。通过不同输入者的语音测试，结合听感对比、目标声线相似度、语音可懂度、实时延迟及连续运行稳定性，验证转换效果。

以上为设计目标，具体实现程度以测试结果为准。

## 本次确定的范围

- 平台：现有野火 Zynq-7020，Vivado 2018.3，优先采用适配本板的 PYNQ 环境。
- 前期只保留一个有效目标档案；支持现场录入、验证、保存和重新注册替换。
- 一次输入一个人的语音，一次输出一条转换语音；多名输入者依次测试。
- 对外功能统一称为“声线转换”。内部开发以稳定音调转换保底，以目标音色逼近为主要研发目标。
- 多目标注册、选择与切换放在单目标验收之后，不进入首轮20天关键路径。
- 真实性、低延迟、隐私收益均须实测；不承诺逼真克隆、任意输入者泛化或身份匿名化。
