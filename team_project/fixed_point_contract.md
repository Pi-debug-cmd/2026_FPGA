# 基础变调定点契约 v1

日期：2026-10-09。算法参考 `src/reference/pitch_shift_fixed.py`，RTL `src/rtl/axis_pitch_shift.v`。本版本是固定比例基础变调，不是目标人物音色模型。

## 数值与状态

| 项 | 约定 |
| --- | --- |
| 输入 | PCM16有符号整数，32位AXI字低16位为样本，上16位须符号扩展 |
| 输出 | 有符号PCM16，符号扩展至32位；一输入对应一输出 |
| 比例 | 18位无符号Q16，32768～131072（0.5～2.0），每次运行固定，改比例前停止/复位 |
| 相位 | 26位无符号，单位1/65536样本，模1024×65536 |
| 相位推进 | 每接收一条非旁路样本，相位加65536−ratio_q16，取低26位；AXI停顿不推进 |
| 缓冲 | 2048×16位，写指针模2048；延迟窗口1024样本，最小延迟2样本 |
| 双读头 | 第二头相位为第一头翻转最高位，即相差512样本 |
| 插值 | 读取write_index−2−floor(phase/65536)及前一个样本；fraction=phase低16位 |
| 插值舍入 | `(recent×(65536−fraction)+older×fraction) >>> 16`，负数向负无穷取整 |
| 第一头权重 | 前半相位为phase>>9，后半为131072−(phase>>9)，范围0～65536 |
| 交叉淡化 | `(tap0×weight+tap1×(65536−weight)) >>> 16`，负数向负无穷取整 |
| 乘加位宽 | 16位有符号样本×18位正权重，34位有符号中间量；权重必须能正值表达65536 |
| 旁路 | ratio_q16=65536时原样输出PCM16；仍写缓冲，保持相位；旁路延迟与变调延迟不同 |

两级计算都是凸组合，合法PCM16输入与权重下结果不超PCM16，无额外增益或限幅。AXI上16位不合法不会被硬件修复；主机必须提供规范符号扩展。比例非法时RTL不接收输入，主机必须先检查，不在运行中临时修改。

## 流与复位

- 时钟同域，低有效同步复位；复位时丢弃正在处理或尚未握手输出的数据。
- 复位释放后依次清零2048个RAM地址，期间TREADY为0；随后才可接收输入。100MHz假设下清零为20.48μs，这是时钟计算，不是板上实测。
- TKEEP/TLAST随输入样本保存并输出，下游背压期间TVALID、数据和侧带保持稳定。v1主机TKEEP固定0xf。
- TLAST仅表示传输块尾，不重置算法状态；算法环形缓冲跨块保留。
- RAM为同步读，顺序读4个样本，插值/淡化再寄存；模块无AXI-Lite、IRQ或板级驱动。接入完整DMA/音频工程时再冻结控制寄存器。

## 本机验证与限制

Python在相同量化比例下与原浮点模型误差门槛小于3 LSB；RAM深度虽由1028改为2048，因读取延迟不超过1026样本，初始化和时间序列保持一致。RTL在6档比例下逐样本对照24576个黄金样本，通过背压、37样本不规则TLAST、RAM/相位回绕和待发送输出复位，日志 `report/pitch_sim.txt`。

尚需：实际语音听感、抗混叠策略、参数切换瞬态、板端格式/时钟适配、长期录放和端到端延迟。升调会把高频移出有效带宽，线性插值不能替代完善抗混叠；正弦或整数一致性通过不等于自然度通过。
