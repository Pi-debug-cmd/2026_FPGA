# PS/PL数据接口草案

状态：未冻结，2026-10-09。适用于先验证PS经DMA接入PL的路线；若选择Codec直连PL，需单独约定音频时钟域，不照搬DMA调度。具体地址、IP实例名、PS配置和引脚均等待本板资料。

| 项目 | 建议v1 | 冻结条件 |
| --- | --- | --- |
| 算法采样率 | 16kHz，单声道 | 音频设备稳定格式确认；48kHz输入的重采样位置单独记录 |
| 样本 | 有符号PCM16 | 标定满幅、通道选择和设备字节序 |
| DMA流字 | 32位，一字一个样本，PCM16符号扩展至32位，小端内存 | 发送/接收按int32数组操作，不能把连续int16数组当32位字 |
| TKEEP | 每字 `0xf` | 每字4个字节均属于传输；符号扩展字节也计入长度 |
| 默认传输块 | 256样本/1024字节 | 16kHz时16ms；按设备与延迟预算复测，不等于算法窗 |
| TLAST | 本次块的最后一个样本握手时置1 | 输出与对应样本一致传播；处理停顿不允许丢标记 |
| 握手 | 只在TVALID与TREADY同时为1时接收或输出 | 下游停顿时输出数据及TLAST保持稳定 |
| 跨块状态 | 延迟缓冲、指针和相位保留 | 不能按TLAST清空算法状态 |
| 旁路 | 保持数据与样本数量 | 时钟延迟另测；作为DMA与打包检查基线 |
| DMA调度 | 接收先就绪，再启动发送 | 等待有超时；错误后按实际DMA/IP复位契约恢复 |
| 参数 | 比例0.5～2.0；第一版每次运行固定 | 定点格式、更新边界和变更瞬态尚未确定 |

浮点参考的窗口默认为1024样本，两个读头相差半个相位周期，权重和为1；它是算法候选，不强制硬件使用相同存储组织。开始/复位后缓冲零填充，启动有效音频区间需标记。比率1的参考直接旁路，后续原声对比必须解释延迟差。

AXI-Lite的候选控制为启停、旁路、状态复位、比例配置与计数读取。先完成流式旁路，再冻结寄存器偏移、比例位宽和参数提交机制。不得在驱动中预填未经Vivado地址图验证的地址。

验证顺序：符号边界向量→不规则块长→连续块→随机背压→TLAST→复位恢复→定点变调。缓存一致性操作按实际PYNQ版本及所用缓冲分配API确定，不凭新版示例推定旧版行为。
