## 二、A3 证据（已终结，10-18）

| 轮次 | 身份 | 泄漏 | UTMOS | 字错 | 结论 |
| --- | --- | --- | --- | --- | --- |
| A1 对照 | 0.190 | 0.172 | 2.035 | 0.167 | — |
| 一：目标包络 + 细节注入 | 0.406 | 0.064 | 1.400 | 0.278 | 自然度不足 |
| 二：+ DTW 帧对齐 | 0.463 | 0.035 | 1.376 | 0.278 | DTW 非瓶颈（解释度 61%） |

- 根因：预测包络相对目标平均谱的**系统性形状偏差**（验证解释度 66%、残余约 3 dB/带），非帧间抖动。

- 规模：54.7k 参数 / int8 55.9 KB / 5.44 MMACs；内容前端另需 924k 参数（0.92 MB int8），须上 PL。
- 复核：lead 用 `tools/eval_candidate.py` 独立复算，数字一致（DCT48 0.459/0.006/1.441/0.278）。
- 证据：`report/a3_neural_feasibility.md`、`a3_neural_round3_summary.json`、`build/generated/a3_neural/postproc_sweep.json`。

## 三、PL 合成卸载证据

### 3.1 CPU 拆解（决定重点）

| 阶段 | 占比 |
| --- | --- |
| 最小相位谱构建 | **84.99%**（其中 exp/cos/sin 62.7%） |
| 激励/响应生成 | 14.70% |
| 重叠相加 | 0.31% |

卸载收益（按 0.55 RTF 反推）：只卸 exp → 全链 0.471；卸整个最小相位 → **0.349**；连激励 → ~0.268。

### 3.2 增量 1：1024 点 IFFT（已达标）

| 项 | 结果 | 判据 |
| --- | --- | --- |
| LUT / FF | 363 / 154 | ≤10k ✅ |
| BRAM | 3 个 RAMB18 当量 | ≤4 ✅ |
| DSP | 4 | ≤8 ✅ |
| WNS @100 MHz | +3.714 ns（0/545 失败） | ≥0 ✅ |
| 仿真 | 行为级 + **后综合 funcsim** 6/6，定点模型 **0 LSB**，vs 浮点 ≤2 LSB | ✅ |
| 吞吐 | 2984 帧/s（需求 100 帧/s 的 29.8×） | ✅ |

### 3.3 增量 2：最小相位加速器（进行中）

- exp 单元定点设计已验证：96 次真实调用、per-bin 最大 3.07e-5、冲激响应 **0.41 LSB**（判据 2 LSB）→ 精度达标。
- 资源预估：与增量 1 合计约 5 BRAM18 / 8 DSP / <3k LUT，在 LUT≤8k、BRAM≤6、DSP≤16 内。
- 待完成：exp 单元 RTL → FFT/IFFT 可切换引擎 → 串联端到端 ≥20 帧比对 + 后综合 funcsim → 板上实测 PS RTF。
