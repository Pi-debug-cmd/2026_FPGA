# 陌生输入者先分析、后固定转换：候选思路

用户提出：“我们可以先把陌生的信息先录入，然后经过算法解算，转化成固定转换，然后完成后开始输出。可以作为一个思路”。

当前解释：陌生输入者本次开始讲话时，系统暂存初始语音，自动估计其特征，结合已注册目标生成本次转换参数，再开始输出。这是用户提出的可探索路线，不是已定方案，也不是本轮录音准备确认。首段长度、是否需要明确结束录入以及换人触发方式尚未确定，不自行假定用户认可某个等待时长。

## 候选流程

1. 目标已注册；输入者此前没有源档案。
2. 接收本次初始讲话，暂存音频并检查有效有声内容。按有效讲话量判断，不只按墙钟计时；静音/噪声不足时不生成未经支持的参数。
3. 从初始讲话估计源特征，结合目标生成转换候选。固定的是本次映射参数，后续仍逐帧提取与保留内容、语调，不能把输出基频固定成一个数。
4. 参数准备后开始转换输出。需比较两种语义：从缓存开头输出，保留首句但携带启动积累的延迟；或初始讲话明确用于分析，准备好后只转换后续讲话。后者会舍弃分析段作为输出内容，必须明确告知，不能暗中丢句。当前尚未选择。
5. 新输入者需要重新估计。首版可探索显式“重新开始”操作，不要求选择个人档案；自动识别换人是独立问题，静音也不能直接等同换人。

## 验证重点

- 把初始等待、准备后持续端到端延迟、每块处理预算分别记录。若完整保留初始缓存并按实时速度连续输出，积累的等待不会在参数生成后自动消失；消除积压需要额外设计，不能宣称后续自然恢复低延迟。
- 初始分析段与随后评价段分开；后者不得回流拟合。测试者仍须是此前未注册的新输入者，但允许本候选明确声明的当次自动分析。
- 比较固定全局配方、自动起始映射及其它可用音色候选。至少逐位检查目标相似度、自然度和内容保持；更准确的音高不等于目标音色达标。
- 现有按源log-F0模块可以作为参数生成实验组件；旧分段数值测试不等于自动流程通过，不立即接入实时默认链路。
- 首段能否估计足够稳定的音色映射仍待实验。若只得到按人升调效果，应调整音色算法，而非无限延长录入。

当前无板卡操作、录音或播放。任何现场采样仍逐轮问准备；大小声适应专项继续后置。
