# 2026-10-14 多输入者转换到同一目标：需求澄清与验收修正

用户补充：“这个需要多个人，每个人都能转化成目标声音，因为今天我让其它人说话的时候感受到这个方案不能保证每个人转化出来的声音相似，而且感觉像是增加固有的音调。”

这是核心功能要求：固定一个已注册目标声线，支持多个不同输入者，每个输入者的转换结果都应接近该目标。既有规划允许输入者短时校准，首期单目标的范围保持；多个输入者是本期必需。用户没有恢复今天的开发或现场测试，本轮仅更新本地需求、计划和交接，继续暂停。

## 现有实现的缺口

当前 src/ps/world_sliding_analysis.h 对所有有声帧固定乘以108722/65536（约1.659），并统一使用1.0975的谱包络变形。参数来自已有单个源/目标配方，实时运行没有按当前输入者加载各自的校准映射。

例如，同样倍率会将80Hz和200Hz输入分别移到约133Hz和332Hz；这是说明固定倍率行为的数值示例，并非今天其他人的实测。统一倍率不会自动将不同输入者的基频分布对齐到同一目标；统一谱包络变形也没有体现各输入者与目标之间的差异。

用户“像是增加固有的音调”的听感与固定升调型实现一致，但缺少其他输入者的独立音频/分段记录，尚不能量化或唯一解释全部音色差异。不能把今天其他人试说自动对应到某个旧测试日志或有声帧计数。

已有“自然连续无异常”仅为对应轮次的自然度/连续性反馈，目标相似度和跨输入者一致性均未通过。运行稳定性、自然度和目标相似度分别验收。

## 恢复后的算法工作顺序

1. 固定目标档案；沿用首期允许每位输入者短时校准的设计，保存源档案，换人时选择或重新校准。自动识别人和免校准适应尚未实现，也不在本轮承诺。
2. 按每位输入者与同一目标的统计差异生成基频映射候选，保留讲话语调变化；不将所有有声帧强制设成同一个频率。清音、静音、低置信度帧沿用合理的保持规则。
3. 核查目标档案中的音色信息，并离线验证源到目标的谱包络映射候选；不假设仅修改倍率或按人校准就足以得到目标身份。
4. 将现有固定配方作为比较基线，用跨输入者留出句判断WORLD候选是否满足核心目标；若相似度没有可重复改善，调整音色算法路线，不能继续仅靠调升调比例或性能优化宣称完成。
5. 稳定性和延迟仍为核心门槛，优化有效音色方案的计算余量。不同讲话音量的适应/失真专项仍按用户要求放到基本功能完成之后，与本次跨输入者要求分别安排。

本次不改运行代码、不构建、不查询板卡、不播放或录音。恢复后，每次需要现场配合仍另问准备状态。

## 首轮跨输入者验收

- 计划至少3位基频范围有差异的输入者，共用同一目标档案；这是后续采样计划，尚未采集或测试。既有规划“至少2名其他输入者”作为最低范围，不作为广泛适用的充分证明。
- 校准句与测试句分离，沿用每位输入者10句留出语句和独立会话。比较原声、仅变调基线、现有固定配方和新的候选映射。
- 分别记录每个输入者的目标相似度、自然度、可懂度、运行日志和失败样本；不只平均，不只用一个输入者的正反馈验收。
- 采用顺序随机的盲听与适合的声学/身份相似度辅助指标；辅助指标不能替代目标相似度听辨。
- 每位输入者的完整候选都应比其仅变调基线更接近目标，同时保留自然度和内容；任何一位未达到要求，都明确列为待改进。具体评分阈值和测法需在正式采集前固定，当前不伪造数值门槛。
- 有限人数测试不能证明任意人均适用；最终需写明实际验证的输入者范围与限制。
