# PS 非周期支路优化原型（候选 c）——最终版：10 ms 帧锚点批量 + 过渡段回退

- 日期：2026-10-18（第二轮：多句验证、听感文件、实时化方案、峰值检查）
- 作用域：`build/generated/ps_opt_20261018/` 与 `report/ps_opt_*`；上游 `build/generated/world_source_v035` 未改（SHA 见 §8）。
  听感文件按 Lead 指定输出到 `data/registrations/source_20261015/speaker01/psopt_comparison/`（仅新增该子目录）。
- **结论一句话**：候选 c 的原始形态（200 ms 批量）质量不达标，否决；改成 **10 ms 帧锚点批量 + 双 vuv 变体 + 过渡段逐脉冲回退** 后，4 句不同内容/说话人的质量全部通过（相关 ≥0.9995、谱差中位 ≤0.35 dB、无削顶），板端 5 s 三句实测 **合成 −19%～−36%、全链 RTF −0.104～−0.160**；听感对照文件已备好但**未上传、未播放**；实时化按滚动锚点窗口设计，内存 180–345 KB、每 200 ms 额外 13–17 ms 计算，预计保留近 100% 离线收益。

## 1. 实现

### 1.1 原理（相对第一轮的修正）

原实现每个脉冲都要算一次"非周期最小相位"：`log(|sp(t)|·ap²(t)) → 镜像 → IFFT → 倒谱折叠 → FFT → 513×(exp,cos,sin)`，即 2 次 1024 FFT + 513 log + 513 exp/cos/sin。5 s 片段有 2023 个脉冲（其中 896 个有声脉冲另有周期支路），因此非周期最小相位调用 **2023 次**，周期支路 **896 次**，合计 2919 次。

候选 c：最小相位谱只依赖参数（sp、ap），与脉冲无关，可在"参数帧"网格上预计算（锚点），脉冲位置对相邻锚点**复谱线性插值**。按 200 ms 批量（stride=20）时质量明显不达标（见 §2.3），最终有效形态是三处修正叠加：

1. **锚点间距 = 1 帧（10 ms）**：每个分析帧一个锚点。5 s 片段 501 个锚点，非周期最小相位调用 2023 → 501 量级，且未发声脉冲不再做 513 次 `pow`/包络准备。锚点间距是质量/速度主旋钮（stride=20 → 200 ms）。
2. **双 vuv 变体锚点**（相对第一轮的关键修正）：上游对未发声脉冲用 `log|sp|`、对发声脉冲用 `log|sp|·ap²`。第一轮只存"发声版"，清浊边界附近的未发声脉冲被错误抑制。现在按脉冲 vuv **只在实际用到的锚点上**计算对应变体（通常每锚点 1 个，边界 ±1 个），实测只多 3–11% 的锚点调用。
3. **过渡区间回退**（质量兜底）：若相邻两锚点的滤波能量比 > `WORLD_AP_FALLBACK_RATIO`（默认 8，≈9 dB），该区间内的脉冲直接用上游逐脉冲最小相位。硬起音/清浊突变的时域平滑误差被绕过，代价是约 7–11% 的脉冲走原路径。
4. **峰值/削顶保护**：质量脚本新增峰值与 16 bit 满幅计数；默认 stride=1 无削顶（见 §2.1）。

### 1.3 一致性 / 中性性

- `stride=0`（保留逐脉冲最小相位、仅走重构后的函数/缓冲区结构）板端 `synthesis_s=2.6556`（基线 2.6548），输出 WAV SHA 与基线**逐位相同**（`25297c07…`）→ 重构本身中性。

### 2.3 为什么 200 ms 批量必须否决（第一轮结论复核）

锚点间距扫描（v0、复谱插值、5 s c0）：

| 锚点间距 | 相关 | RMS 差/参考 | 谱差中位 | p95 | 结论 |
|---|---|---|---|---|---|
| 10 ms | 0.996817 | 0.0799 | 0.271 dB | 2.59 dB | 通过（建议门槛） |
| 20 ms | 0.984298 | 0.1765 | 0.873 dB | 7.50 dB | 不通过 |
| 50 ms | 0.983170 | 0.1831 | 1.486 dB | 11.63 dB | 不通过（且削顶） |
| 100 ms | 0.981233 | 0.1929 | 2.075 dB | 15.43 dB | 不通过 |
| 200 ms | 0.978444 | 0.2065 | 2.535 dB | 20.97 dB | 明确否决 |

原因：合成器按 **10 ms 参数帧**插值 sp/ap；参数"200 ms 更新一次"不等于滤波器 200 ms 不变，最小相位必须跟到 10 ms 尺度才有足够质量。

### 2.4 q1（唯一先失败的句子）定位过程

- 失败现象：q1（0.9732、24.7% RMS 差）几乎全部来自**文件开头 100 ms 的硬起音**：diff 能量 97.5% 集中在 0–0.5 s；**去掉前 0.5 s 后相关 0.9986**、RMS 差 5.3%，中段 1–4 s 相关 0.9996。
- 用 0.5 s 前导零把起音挪到 0.5 s：失败随之**移动**到 0.4–0.6 s（该处占 99.4% diff 能量），后半段正常 → 不是"清浊切换比例"敏感性，而是**硬起音/突变处的时域平滑误差**。
- 逐脉冲滤波能量对比（调试开关）：起音前 5 个脉冲 anchor/reference 滤波能量比 0.82/0.63/0.44/0.25/0.36（最多 −12 dB），第 6 个脉冲起恢复 0.99 → 与"平滑把突变抹平"一致；双变体修正了清浊错配，回退则彻底绕过突变区间，两处叠加后 q1 通过且余量最大。

## 4. 实时化方案（设计 + 估算，本轮不实现）

### 4.1 滚动锚点窗口

不能用 4.1 MB 的整段锚点表。实时流式下参数每 **200 ms 更新一次**（20 帧 × 10 ms），合成滞后于参数（现有 200 ms 级 FIFO/启动前缀）：

- **窗口长度**：环形缓冲保存 `上一块最后 1 个锚点 + 当前块 20 个锚点 + 下一块首锚点（预取）`，即 **22 个锚点**；若实现取两整块 + 两个边界，则 **42 个锚点**（最坏情况含两套 vuv 变体）。
- **内存**：单锚点 = 513 bin × 2 × 8 B = 8.2 KB；**22 锚点 ≈ 180 KB，42 锚点 ≈ 345 KB**（只在用到的锚点/变体上分配）；另有参数帧本身（每块 20×513×2×8≈164 KB，现设计已有）。远小于离线 4.1 MB，且 180–345 KB 更容易命中 512 KB L2。
- **更新策略**：收到 200 ms 参数块时，为 20 个新帧计算锚点（每帧 1 次最小相位；仅清浊边界 ±1 帧需要第二变体）；上一块末锚点保留用于插值；合成队列滞后 ≥1 块，因此"下一块首锚点"在需要前已到达。若某块因调度未到，则退化为逐脉冲回退（质量不变、速度降低）。
- **计算分布**：不做集中突发，**惰性预取**——当脉冲进入区间 k 时计算锚点 k+1（约每 2 个脉冲 0.65 ms，即每 ~5 ms 一次），把 200 ms 一次 13 ms 的突发摊平。
- **过渡段回退**：区间能量比判定在锚点建立时完成；回退脉冲需要的 sp/ap 本来就在参数流里，不额外存储。

### 4.2 计算预算（基于板端实测）

- 每 200 ms 需要 20 个锚点 × 0.65 ms ≈ **13 ms**；回退脉冲 c0 平均 5.5 个/200 ms × 0.75 ms ≈ **4 ms**；合计 **~17 ms/200 ms**（占 8.5% wall）。
- 现在（离线）合成本身 = 1.854 s/5 s ≈ **74 ms/200 ms**；加实时化开销后 ≈ 91 ms/200 ms，仍有 ~2.2× 实时余量；若惰性摊平，则单次突发 ≤1 ms。
- 对照：基线合成 2.655 s/5 s ≈ 106 ms/200 ms；本方案在流式下每块约省 15 ms 合成时间。

### 4.3 收益保留估算

- 流式与离线的**调用次数相同**（每 200 ms 20 个锚点，等价 100 锚点/s；离线 stride=1 也是 100/s），因此理论上保留 **≈100%** 的离线收益（−0.160 RTF）。
- 折扣项：FIFO 调度/缓存行为（锚点窗口更小、更易命中 L2，偏正）、回退路径的 sp/ap 读取（已有）、实现初期不启用惰性预取的突发抖动（建议预留 10–15% 余量）。**保守估计实时化后可保留 −0.14～−0.16 RTF**（合成 RTF 0.53→约 0.37，全链约 0.65）。
- 实施顺序：① 先在 `synthesisrealtime.cpp` 复刻锚点表 + 回退（保持 API 不变）；② 现有流式主机 16 项检查 + PCM 对比；③ 板端 60 s 零欠载门槛；④ 再评估是否与 PL 卸载叠加（两者收益重叠，本项已省 1364/2919 次最小相位调用）。

## 6. 风险

1. **残余时域平滑误差**：回退只覆盖能量跳变大的区间；能量变化平缓但相位变化快的区间仍有小误差（4 句 p95 2.0–2.7 dB，最差帧中位 ≤1.26 dB）。听感必须真人确认（本轮按规则不播放）；如需更保守可把回退阈值降到 2–4（质量更好、板端合成 +0.1～0.5 s）。
2. **回退比例随素材变化**：c0/q1/q2/q3 为 6.8%/9.1%/10.5%/10.9%，收益随之从 −0.160 到 −0.104 波动；极端连续清音/爆破素材会更低。
3. **硬起音/首帧**：q1 说明硬起音是主要误差源；实时化后起音来自运行中的参数流（非文件第 0 帧），回退区间判定同样适用，但需要流式回归确认。
4. **实时化未实现**：4.1–4.3 是设计与估算，未改 `synthesisrealtime.cpp`，无流式实测证据。
5. **内存/缓存**：离线锚点表约 4.1 MB（stride=1、单变体；双变体只在边界少量增加）；流式滚动窗口 180–345 KB，仍需在板上验证 L2 行为。
6. **与 PL 路线重叠**：本项已省 1364/2919 次最小相位调用；PL 卸载最小相位的预期收益要扣除这部分，不宜再按原估算排优先级。
7. **确定性**：宿主/ARM 输出逐位一致、randn 序列不变，无跨平台漂移；但任何未来改动（如开启 mode1）都会改变输出，需重新过质量门槛。

## 7. 值不值得做：**值得，按"10 ms 锚点 + 双变体 + 回退 8×"采纳**

- **收益**：板端 4 句实测合成 −19%～−36%（c0 −30.2%，2.655→1.854 s/5 s），全链 RTF **−0.104～−0.160**（c0 0.8087→0.6488，−19.8%）；纯 PS、无 PL、无硬件改动、实现仅一个算法文件。
- **质量**：4 句相关 ≥0.9995、谱差中位 ≤0.35 dB、无削顶，均远超建议门槛；第一轮失败的 q1 已被回退修正。
- **代价**：离线锚点表（流式化后 180–345 KB）；每 200 ms 约 13–17 ms 额外计算，实时余量仍 >2×；实现复杂度中等（锚点表 + 回退判定）。
- **否决**：200 ms 批量（原候选 c 字面方案）质量不达标；mode1（幅值校正）板上 +0.26 s 换小幅质量，不划算；不推荐不回退的版本（q1 类素材会掉到 0.974）。
- **前置动作**：① 真人 A/B 听感（文件已备好）；② 实时流式改造 + 现有 16 项主机检查 + 60 s 零欠载；③ 之后重新评估 PL 卸载优先级。

## 9. 局限

1. 质量用 4 句（1 个既有 c0 + 3 个 5 s 片段）验证，未覆盖极端低音/高音/长静音；听感未做（规则禁止播放）。
2. 实时化只有设计与估算，未实现流式版本、未做实时回归；滚动窗口的 L2/调度行为未实测。
3. 回退阈值 8× 是 4 句折中，未做听感调参；严格阈值（2–4×）质量更好但成本更高。
4. ARM 基线与历史人工报告（rtf 0.825/2.717 s）不同：本轮统一用新 ARM 基线 flags（−2.6%，与给定结论一致），所有比较均用同轮 baseline 二进制。
5. 听感对照用的目标原声素材为 16 kHz 已注册素材（非 32 kHz 原始录音），三段统一按既有 `a1_a3_comparison` 约定 16 k→32 k；只用于相对 A/B。
