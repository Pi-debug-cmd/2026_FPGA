# PL-20261027-01 Round22：录入提示音与准备窗口

## 结论

用户在 Round21 后补充：**“因为刚刚录入的时候我没有准备好，你录入之前先给个提示音”**。因此 Round21 的原始“没听到声音”及客观日志继续保留，但不再把该轮当成候选可听性失败的有效归因证据；当时的操作者准备条件无效。

实时监督器现支持显式 `--prompt-tone --ready-delay-s 2`：完成 mixer 配置后先在正式播放同一路径输出两段上升提示音，提示结束后等待 2 秒，之后才启动 arecord、WORLD 和 aplay。提示音失败时正式录入不会开始。

## 提示契约

- 格式：32 kHz、S24_LE、双声道，与正式 WORLD 播放路径一致。
- 波形：880 Hz 300 ms，静音 180 ms，1175 Hz 300 ms。
- 峰值：满量程的 12%，每段首尾约 10 ms 线性淡入淡出，避免点击声。
- 总提示帧：24,960；提示后静默准备窗口默认 2.0 秒，可选范围 0.5～5 秒。
- 顺序：保存 mixer → 配置 mixer → 提示音 → 2 秒准备 → 启动采录放。
- 证据：结果 JSON 保存 `prompt_tone_requested`、`ready_delay_s`、提示 exit、帧数和峰值。
