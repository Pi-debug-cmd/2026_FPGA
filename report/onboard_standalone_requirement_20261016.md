用户原话：“我们的多陌生声源转化目标音色，是完全脱机的，也就是在准备阶段，在板子上完成音色转化模型的构建，实时转化阶段，同样是在板子上”；随后补充“我需要多陌生声源转化目标声源全裸机，你觉得改用哪个”，并在目标进板方式上选择“完全现场：演示时在板上录目标人几句话，当场建模”。

## 我方理解（待用户最终确认的一点）

1. 比赛演示时电脑不在环：目标建模与实时转换两阶段都只由 Zynq-7020 板卡完成，不依赖 PC/GPU/云。
2. 目标音色来源为**演示现场在板上录制的目标人几句话**，板上当场建模；不是把预置配置文件拷进板子。
3. 输入者仍为未录入、未校准的陌生说话人（沿用 report/source_uncalibrated_requirement_20261015.md），不得要求源档案或预读校准句。
4. 待确认的唯一分叉：“全裸机”是否等于**无操作系统**（无 Linux/PYNQ/ALSA）。若只是“不接电脑、板上自足”，现有 Linux 板端可继续用；若硬性要求无 OS，则音频链、驱动 ABI 与 PYNQ 路线需重写。

## 该约束直接排除的方案

- PC 上生成配置文件再上传（现行 world_registration.py + configuration_cue_v2.json 流程）不再合规，建模必须移植到板上。
- Seed-VC 参考（report/seed_reference_audit_20261016.json）只能作为研发期上限参考：约 363M 参数、FP32 约 1.45GB＞本板 1GB DDR、30 步顺序扩散、主机 CPU RTF≈2.60，不可能上板。
- 依赖 PC 训练的路线只在“开发期定型、比赛期不训练”的前提下可用于研发，不能把训练本身放进演示流程。

## 准备阶段的两项板上任务（用户 2026-10-16 补充提醒）

准备阶段不是只有“建模”，而是两项，且都在板上、都不接电脑：

### 任务 A：现场注册目标声源

- 板上引导录制目标人若干句（沿用已有提示音规则：先提示音、间隔后再采集；提示音不并入注册录音），原生 32k/S24_LE 采集后降为 16k 单声道。
- 板上做注册质量门槛，不合格必须拒绝并要求重录，不能拿坏录音建模：总时长与有声帧下限、原始触顶/削顶检测、静音与噪声下限、通道与增益规范；历史上已有“准备片段触顶 4 帧被拒绝”的先例，沿用同一严格度。
- 注册产物是**目标画像参数**（不是原始波形）：F0 分布（中位/分位/范围）、平均谱包络与共振峰尺度、AP/气声统计、必要的响度与增益基准；附校验值并可加载复用。
- 必须支持重注册与回退：换目标可重新注册；新画像不合格时保留上一份可用画像，不破坏当前可运行版本。
- 注册落盘位置限板卡 rootfs（例如 /home/root 下独立目录），不动 SD 启动分区、不重写整卡。

### 任务 B：板上构建音色转化模型

- 以任务 A 的画像为输入，在板上完成转换所需的参数/条件构建（参数化路线为映射与谱包络目标化参数；若走神经路线则为目标条件向量），全程无 PC。
- 构建结果需可复现：同一注册录音重复构建应得到一致（或差异有界）的产物并留校验值。

### 注册的验收口径（建议，待用户确认）

1. 现场录目标话 → 板上出画像 → 立刻用**同一目标的新句**跑一次转换，画像稳定、不崩、不静音。
2. 注册拒绝路径可复现：故意录一段过短/触顶/静音的音频，板上必须拒绝并给出可读原因。
3. 重注册与回退演练一次：换一份画像后仍能回到上一份可运行状态。
4. 全流程断开 PC，只用板卡、麦克风与音响完成。

任务 A/B 与“用参数化还是用轻量网络”这一路线选择相互独立，属共同前置；建议与转换路线的判决性实验并行推进，先做板上注册链路。

## 建议路线（本轮由助手提出，待用户确认）

主干（保底，必须交付）：**板上现场目标建模 + 目标条件化的参数化实时转换（WORLD 系）**

- 目标建模（板上，秒级～几十秒）：录目标 5～10 句 → 板上算目标画像：F0 分布（中位/分位/范围）、平均谱包络与共振峰尺度、AP/气声统计，以及必要的起止与增益规范。
- 实时转换（板上，源免校准）：逐帧源 F0 + 谱包络 → 按目标画像做 F0 统计映射与谱包络目标化 → AP 处理 → 合成输出。沿用已验证的板端流式框架（v22 系：有界 FIFO、200ms 更新、监督与 mixer 恢复）。
- 已知短板与主攻方向：今日审计量化出现役 WORLD 旧配方对目标质心身份余弦仅 0.216、对源泄漏 0.383，而目标四轨自身两两 0.911。**“源特征残留”就是核心研发点**，不是延迟或功能项。

加分（并行验证，不达标不接入）：**开发期定型的轻量 any-to-one 网络**

- 结构在开发期由 PC 定型（可参考 Seed-VC/LLVC 作为教师），比赛中板上只做前向推理，目标条件由板上录制的目标语音当算出。
- 接入门槛：PC 上身份/自然度/内容三项明显优于主干，且板上能实时（含 PL 加速）、不掉帧、可回退。
