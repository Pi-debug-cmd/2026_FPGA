## 0b. 第二轮结果（2026-10-18 下午追加）

### 0b.1 帧级 DTW 对齐（最高优先项）

- 做法：源/教师各自 CMN 后的 48 band log-mel 拼接 1.5×有声指示维，做 `librosa.sequence.dtw`
  单调对齐；每个源帧取教师路径索引均值并做单调插值。192/192 对全部重建（`14_dtw_align.py`）。
- 对齐统计（`dtw_alignment.json`）：**平均 |时移| 0.69 帧（6.9 ms）**，最大 26 帧；
   **9/192 句**局部漂移 >100 ms，2 句 >200 ms。多数句子的全局对齐本来就不差，局部漂移只存在于少数句。
- **解释度（lead 指定的判据）**：

  | 轮次 | 验证零残差基线 MAE | 模型验证 MAE | 解释度 |
  | --- | --- | --- | --- |
  | 第一轮（全局移位） | 2.482 | 0.934 | **62.4%** |
  | 第二轮（DTW） | 2.174 | 0.849 | **61.0%** |

  绝对谱误差下降 9.1%（0.934→0.849），但解释度没有上升（目标 >80% 未达）。
  **结论：对齐不是主瓶颈。** 按 lead 要求立即回报，原“对齐是瓶颈之一”的判断需要修正；
  不再把帧级对齐列为第一优先级。
- 对指标的影响（同一 speaker01 窗口/评价器）：身份 **0.400→0.463**、泄漏 0.019→0.035、
  UTMOS 1.321→1.376、字错 **0.500→0.278**；16 句留出源说话人身份 **0.428→0.458**。
  对齐虽没解决解释度，但确实让身份与内容明显变好。

### 0b.2 内容保持约束

- 逐 bin 相对源包络的软限幅（`D·tanh(Δ/D)`，D=4/6/8 dB）实测**方向不可行**：
  身份崩到 **0.031 / 0.027 / 0.057**，泄漏回到 0.55（≈源）。原因是目标音色本身就是相对源包络的
  大幅逐 bin 静态偏差（A/B 画像均值谱差 L1 0.61），限幅等于把转换拉回源。
- 真正有效的内容杠杆仍是“源包络时域细节注入”：DTW 模型 + β=0.5 →
  **身份 0.435、泄漏 0.020、UTMOS 1.450、字错 0.278**。字错从 0.500 降到 0.278，
  但到不了 0.20；UTMOS 到 1.45，到不了 1.9。
- mel 倒谱距离损失没有再单独加：它与逐 bin 限幅同方向、会直接对抗身份，已有证据判断不值得。

### 0b.3 条件有效性自检（伪第二/第三目标）

- 构造：伪目标 B = 真实目标 T5–8 的受控变换（F0×1.26、包络频率轴×1.15）；
  C =（F0×0.80、×0.90，训练不出现，做外推检验）。用同一批源句同时训练 A/B 两套标签的
  条件模型：profile 输入 = 4 项 F0 统计 + 16 阶画像谱 DCT，56,753 参数（`17_train_cond.py`）。
- 同一源句分别用 A/B/C 画像转换，两个源句（开发句 + 1 句留出对）结论一致：
  - F0 中位比 B/A = **1.256 / 1.260**（设定 1.26）✓；
  - 输出包络到自身画像更近：A 1.649 < 1.909（到 B）；B 1.651 < 1.670（到 A）✓；
  - WeSpeaker：A 输出对质心 A **0.369** vs 质心 B 0.124；B 输出对质心 B **0.454** vs 质心 A 0.022 ✓；
  - 残差随画像改变：|res_A−res_B| = 0.52-0.53（画像均值谱差 0.61；
    输出差/均值谱差 = 1.02-1.18）→ **条件不只是输出偏置**，但画像均值谱仍占主导。
- 外推 C：包络最近 C 画像 ✓，但 F0 只外推到 **0.896**（设定 0.80）；声纹上 C 输出反而更像真实 A
  （0.439 vs C 0.245）——合成同人变换不能当真正的第二说话人质心。
- **结论**：条件对分布内伪目标（A/B）确实生效（F0/谱/声纹三路证据一致）；对训练外变换只部分外推；
  真正的多目标泛化仍需 2–3 个真实目标说话人语料。代价：条件模型在真实目标 A 上身份
  0.369（无条件 DTW 0.463），说明加条件输入会稀释单目标精度。

## 0c. 第三轮结果（2026-10-18 晚，限时收尾实验）

> 本轮目标：只做两件事（内容条件突破解释度、波形级折中），硬截止 10/21 中午；
> 杀停线：解释度 <75% 或 UTMOS <1.8 → A3 停止。**两条都触发，A3 停止建模。**

### 0c.1 实验 1：内容条件（reduced LLVC 6 层编码器）

- 特征：`build/llvc_host_model.py` 加载 `reduced_student_v2/final.pt`（原 LLVC 架构、label 固定零），
  取 `mask_gen.encoder`（DilatedCausalConvEncoder，6 层、enc_dim=384、1 kHz latent）输出，
  10 token 平均成 100 Hz 与 WORLD 帧对齐；训练集上 PCA 到 64 维（解释方差 95.8%），±2 帧上下文。
- 回归头输入 = 内容 PCA 64×5 + 源 CMN 48 band log-mel + 4 项源统计 + 20 维目标画像
  （F0 统计 + 画像谱 DCT），hidden 192，**121,969 参数**；输出仍是目标包络残差 + 目标 logF0，
  WORLD 合成不变（不换声码器）。
- 结果（`eval3_content.json`，同一 2.68 s+4.8 s 协议）：

| 项 | 第二轮最好 | 第三轮内容条件 | 变化 |
| --- | --- | --- | --- |
| 验证集解释度 | 61.0% | **66.0%** | +5.0 pt（目标 >75% 未达） |
| 验证谱 MAE（log-mel） | 0.849 | **0.739** | −13.0% |
| 身份（speaker01） | 0.463 | **0.561** | +0.098，已到 Seed-VC 参考（0.551）水平 |
| 泄漏 | 0.035 | 0.095 | 略升，仍优于 A1（0.172） |
| UTMOS | 1.376 | 1.401 | 基本不变，**<1.8 杀停线** |
| 字错 | 0.278 | **0.056** | 大幅改善（A1 0.167） |
| 留出源说话人身份（16 句） | 0.458 | **0.532** | +0.074 |

- **结论**：内容编码器确实是“身份/内容”的强杠杆（身份 0.561、字错 0.056），
  但自然度没有跟着上来（1.40），解释度也只到 66%（<75%）。**杀停线触发，A3 停止建模。**
- 部署代价（如果续做）：内容前端（in_conv + convnet_pre + 6 层 DCC）**924,000 参数**，
  int8 约 **0.92 MB**、FP32 约 3.7 MB；它是 1 kHz latent，PS 侧估算 0.5–0.8 RTF
  （历史整套 reduced student 在 PS 约 0.98 RTF），**必须搬 PL**；回归头 122k 参数
  （int8 约 122 KB）仍很小。即：身份上来了，但“极小块 PS 预算”的优势被内容编码器吃掉，
  A3 的形态会向 LLVC 靠拢。

### 0c.3 第三轮判定（最终）

- **A3 路线停止建模**：杀停线（解释度 <75%、UTMOS <1.8）两条都触发，不再扩结构/调参。
- 本轮最大收获是定位到“内容特征”这个强变量：身份 0.561、字错 0.056 已接近 Seed-VC 参考，
  但参数域 WORLD 合成下的自然度停在 1.40；要提高自然度需要换合成/声码器（超出 A3 参数域范围），
  或接受“身份高但不自然”的方案。
- **工程建议不变：主线继续 A1（0.190/0.172/2.035/0.167）**；A3 结论写进技术报告：
  身份上限可到 0.53–0.56（教师 0.87），瓶颈是包络可预测性与 WORLD 自然度，不是模型容量或对齐。

  主线继续 A1；A3 作为技术结论保留：内容特征能把身份/内容做到 0.561/0.056，但参数域 WORLD

### 1.3 数据限制与泄漏风险（必须写清）

- **单目标说话人**：目标侧只有一个人。A3 的 profile 条件维度存在并已接入，但本语料无法证明它
  能适配不同目标；只能验证“同一目标换一段新录音/新文本”的情形。
- **教师伪标签自带目标身份**：抽样 8 个教师 wav 对目标质心余弦 **0.870**（源输入仅 0.116，目标
  自身 Track9 0.940）。也就是说训练标签本身就是目标音色——按比赛规则“开发期可训练、比赛期不训练”
  是合规的，但这也意味着**当前 A3 实质上是“到这个已知目标的 any-to-one”**，不是已证实的多目标条件化。
- **身份质心与注册共用 T5–8**：身份指标天然偏乐观，与历史 A1/Seed 数字同一口径，可横向比、不可当绝对值。
- **源域不匹配**：192 对源是干净 44.1 kHz 数据集录音；真正测试的 speaker01 是板端 16 kHz 采集
  （带房间/链路特征），属于域外输入。
- **只能做留出的部分**：目标 Track 9（22.8 s）只用于留出验证，不参与任何训练/画像；源侧 speaker01
  （开发句）完全未参与训练；训练内部再留 2 个源说话人（SSB0043、SSB0394，16 句）做验证，
  最终测试不动这两人的数字。
- 源与教师逐文件时长差最大 30 ms、均值 14 ms，已用能量包络互相关做全局对齐（≤2 帧）；
  **句内局部时间漂移没有处理**，这是包络回归精度上不去的重要原因之一。

## 2. 方法与实现（交付项 2）

技术形态按建议选**参数域条件映射**，复用现有 WORLD 合成，不引入新声码器。

```
源音频 16k
  → WORLD 分析（DIO speed4 + StoneMask + 能量门限 + CheapTrick fft1024；与板端 A1 同参数）
  → 逐帧特征：
       48 band log-mel 上下文（±2 帧，句内 CMN，5×48=240 维）
       + 句内 F0 归一化 z、源 F0 中位/展宽、源有声比例（4 维）
       + 目标画像 F0 四项统计（4 维）
  → 3 层 MLP（248→128→128→49）
       输出：48 维目标谱残差（相对目标画像均值谱）+ 1 维目标 logF0
  → 目标 48 band log-mel = 画像均值谱 + 预测残差，再用 pinv(M) 重建 513 bin 谱包络
    （A3 不做 A1 那种逐频点 ±3 dB 钳位；重建误差在前端对比里单独测过）
  → 目标 F0 = exp(预测 logF0)，清音帧沿用源清浊判决
  → AP 沿用源 AP（与 A1 一致）
  → WORLD 合成 16 kHz
```

- 训练：192 对、88,810 帧（48,469 有声帧），Adam，800 步，batch 2048，CPU 约 10 s；
  损失 = 谱残差 L1（按帧能量加权）+ 目标 logF0 L1（仅双方有声帧）。留 2 个源说话人做验证/选步。
- **折中技巧（最佳版本使用）**：把“源包络相对其 70 ms 时间平滑的细节”按 β=0.75 加回预测目标包络
  （`pred + 0.75·(src − smooth(src))`），身份不变（0.400→0.406）而字错从 0.500 降到 0.278。
  实测这是“身份 vs 自然度/内容”折中最有效的一项，且无需重训。
- 前端对比（`06_frontend_compare.py`，用教师音频做 oracle 重建）：

| 前端 | 身份 | UTMOS | log 谱 MAE |
| --- | --- | --- | --- |
| mel48 + pinv（最终采用） | 0.756 | 2.257 | 2.06 |
| mel48 + log 插值 | 0.769 | 2.240 | 2.42 |
| mel80 + pinv | 0.792 | 2.294 | 1.49 |
| DCT48 / DCT80（倒谱截断） | **0.831 / 0.835** | **2.348 / 2.367** | 0.076 / 0.015 |
| 教师音频原声（上限参考） | 0.885 | — | — |

  结论：**前端不是瓶颈**（DCT 上限更高，但训练出的 DCT 版模型 F0 头回归失败，中位 313 Hz，
  反而更差，见 §3.3），所以最终仍用简单、板端友好的 mel48+pinv。DCT 版留作下一步。

## 3. 四项指标（交付项 2，与 A1 完全同协议）

评价器与窗口直接复用 `build/audit_seed_reference_20261016.py` 的 `Evaluators / cer / f0_stats`
和 `build/check_world_convert_board.py` 的窗口：20 s 输入，取 **2.68 s 起 4.8 s**；目标质心 Tracks 5–8；
泄漏向量取同一源窗口；ASR 为 Whisper-small（中文）相对源转写算字错。

**协议自检**：同一脚本对现役板端输出 `closed_loop_arm.wav` 复算得到
**0.1903 / 0.1719 / 2.0354 / 0.1667**，与 `report/world_convert_board_20261017.json` 完全一致，
因此下表数字可直接与历史数字对照。

### 3.1 主结果

| 输出 | 身份↑ | 源泄漏↓ | UTMOS↑ | 字错↓ | 说明 |
| --- | --- | --- | --- | --- | --- |
| **现役 A1（板上闭环）** | 0.1903 | 0.1719 | 2.0354 | 0.1667 | 参考基线 |
| **A3 v1 + 细节注入 β=0.75（最佳折中）** | **0.4064** | **0.0642** | 1.3997 | 0.2778 | 本报告主推 |
| A3 v1 纯模型（最低泄漏） | 0.4000 | **0.0191** | 1.3213 | 0.5000 | 身份/泄漏最好，内容差 |
| A3 v1 细节注入 β=0.50 | 0.4019 | 0.0486 | 1.3819 | 0.2222 | 字错更低、UTMOS 略低 |
| A3 v1 × 源包络混合 a=0.85 | 0.3606 | 0.0904 | 1.3177 | 0.5000 | 混合不优于细节注入 |

历史参考：旧配方 0.216/0.383/2.095；Seed-VC 0.551/0.021/2.736/0.111（不可上板）。
目标自身两两余弦 0.911；教师音频身份 0.885（4 句）/0.870（8 句抽样）；教师音频 WORLD 再合成 0.836。

### 3.2 泛化抽查（未参与训练的源说话人，仅身份）

留出 2 个源说话人（SSB0043/SSB0394，16 句）整句转换后：

| | 源输入 | 教师（标签） | A3 输出 |
| --- | --- | --- | --- |
| 对目标质心余弦均值 | 0.032 | 0.873 | **0.428** |

即 A3 在**未见过的源说话人**上稳定拿到 0.43 左右，不是开发句过拟合的偶然值；同时说明
“教师 0.87 → A3 0.43”之间还有约一半差距可挖。

### 3.3 归因（为什么自然度上不去）

在留出对上做“换 F0 / 换包络”拆解（`naturalness_attribution.json`，6 句均值）：

| 版本 | UTMOS | 身份 |
| --- | --- | --- |
| 教师 wav 原声 | 3.67 | 0.865 |
| 教师参数 WORLD 再合成（声码器上限） | 2.67 | 0.797 |
| A3 预测包络 + 教师 F0（oracle F0） | 1.345 | 0.518 |
| **A3 完整（预测包络+预测 F0）** | **1.317** | 0.404 |
| 源参数再合成（输入自身） | 1.482 | 0.035 |

- 换成 oracle F0 只把 UTMOS 从 1.317 提到 1.345 → **F0 不是主因**；
- 预测包络 + oracle F0 仍只有 1.345，而教师包络再合成 2.67 → **主因是预测的目标包络本身不够准/不够自然**；
- 验证集解释度：目标包络相对画像均值的 MAE 2.48 log-mel，模型做到 0.93（解释 62.4%），
  剩余误差约 2.7 dB/带，足以听出“糊/机器人味”，也解释了字错偏高；
- 细节注入能把字错拉回 0.28（源细节带可懂度），但补不回音色预测误差。

## 4. 规模与预算（交付项 3）

| 项 | 数值 |
| --- | --- |
| 参数量 | **54,705**（248×128 + 128×128 + 128×49） |
| FP32 权重 | 约 214 KB（checkpoint 219 KB 含优化器外的元数据） |
| **int8 部署大小** | **55,876 B ≈ 54.6 KB**（权重 54,400 B + 每通道 fp32 scale） |
| 每帧 MAC | **54,400**（100 帧/秒 → 5.44 MMAC/s） |
| 每帧激活 | 约 2.2 KB |
| PS 侧 RTF（网络） | **0.0054（1 GMAC/s）～0.0181（300 MMAC/s）～0.0544（保守 100 MMAC/s）** |
| 与 A1 映射阶段比 | 0.37×～3.7×（A1 映射实测 0.0146 RTF），仍 ≤0.3 RTF 门槛 |
| 替换映射后整链 RTF | 0.805～0.854（A1 实测 0.816），**几乎不变** |
| PL 兼容 | 3 个 int8 GEMM，可直接复用已上板验证的 `gemm_s8`；PL 侧 5.44 MMAC/s 对 220 DSP 可忽略 |

**预算结论**：模型本身完全满足“PS 侧 ≤0.3 RTF”，且比 LLVC int8 学生（2.6 MB、16 GEMM）小两个量级。
但 A3 仍然复用 WORLD 合成（0.550）+ 分析（0.250），PS 单干总 RTF 还是 0.81——**要压到 0.3 必须把
合成（或合成+D4C）交 PL**，这与 A1 的既有结论相同，A3 不改变实时预算结构。反过来，A3 的
优势是“换身份不换声码器”，所以 PL 上只需加 3 个 GEMM，不需要新的神经声码器。

> 说明：以上 RTF 是**分析估算**（按 A9 int8 GEMM 有效吞吐 100M/300M/1G MAC/s 三档），不是板端实测；
> 本轮严禁上板，未做 ARM 计时。int8 量化本身也未做，fp32 指标是上限参考。

## 5. 判定与理由（交付项 4）

**值得继续，但只作为加分/备选路线，不替换 A1。** 理由：

1. **身份门槛明确通过且不是巧合**：开发句 0.406、16 句未见源说话人 0.428，都稳定高于 0.35；
   同时源泄漏 0.064（A1 0.172），是“目标像、源不像”的第一次同时达标。
2. **模型规模/实时性没有障碍**：55 KB、5.4 MMAC/s、3 个 GEMM，PS 侧 ≤0.055 RTF；甚至可整网搬 PL。
3. **但自然度/内容明显退步**：UTMOS 1.40 vs 2.04、字错 0.278 vs 0.167。比赛演示是听感导向的，
   以当前状态替换 A1 风险大于收益。
4. **瓶颈已定位且可攻**：预测包络精度/源-教师句内对齐，而不是前端、不是 F0、不是模型容量。

**硬性建议**：给 A3 一到两周定向攻关，验收线 **身份≥0.35 且 UTMOS≥1.9 且字错≤0.20 且能 int8 量化**；
不达标就把 A3 的结论（身份上限 0.43、包络回归是瓶颈）写进技术报告，主线继续用 A1。

## 6. 若继续，下一步优先级

1. **句内对齐**：用 DTW 把源/教师 mel 对齐后再做逐帧回归（或改用时序模型 + 对齐不变损失）。
   当前只有全局 ±2 帧移位，局部漂移会直接把监督信号抹平。
2. **时序模型**：把逐帧 MLP 换成 3–5 层因果 TCN（或双向 GRU 仅离线），扩大感受野到 100–200 ms；
   参数量控制在 100–200k、int8 ≤200 KB，仍在预算内。
3. **预测“变换”而非“绝对包络”**：输出相对源包络的残差（warp+倾斜+精细修正），保源细节、学目标形状，
   有望同时保住 UTMOS 与身份。
4. **多目标数据**：至少再收 2–3 个目标说话人的成对/伪标签，才能真正验证 profile 条件化与重注册，
   这是比赛需求的核心，也是当前最大空白。
5. **量化与板端计时**：int8 逐层量化 + A9 实测 RTF（需另开板卡窗口，本轮禁止）。

## 7. 限制与未做

- 未上板、未录音/放音、未切 PL、未改启动分区；所有 RTF 为估算。
- int8 量化、量化后身份/自然度未测；F0 头对量化最敏感，需单独处理。
- 只用 1 句开发句做四项主评价（与历史 A1 同句同窗口，可比但非盲评）；泛化用 16 句留出对，
  这两个说话人在历史开发中被用过，仍不是严格盲测。
- UTMOS 是跨域预测器，对中文/世界声码器输出未校准；字错是 ASR 相对比较，不是真值。
- A3 的“目标条件”在当前单目标语料下无法与“any-to-one 固定目标”区分开。
