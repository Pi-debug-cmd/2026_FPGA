# 2026-10-15 输入者免录入、免校准：权威需求修正

用户明确：“我需要任何没有经过录入校准的人来说话都能转化为目标声音”。此前把每位源说话人短时校准作为使用前提是助手理解错误，不是用户同意的限制。本记录覆盖10月14日和今天早些时候有关“允许先按输入者校准”的执行前提。

## 使用要求

- 注册目标声音；输入者无需录入、源档案、人工选择身份、指定个人倍率或先读校准句，直接讲话转换到已注册目标。
- 推理过程可以从当前输入提取必要特征，但不得把预先校准改名为“热身”后继续要求用户配合；在线统计、首句等待和换人污染均需明确测量，不能预设已满足要求。
- 源身份泛化与目标注册分别验证。免源校准的固定目标模型，不自动满足现场注册新目标；保持单目标注册的原范围，不默默换成只能使用一个训练好的人物。
- 无法以少量测试证明任何人的声音均保证同样效果；研发目标是对未见源说话人泛化，报告实际覆盖范围与失败边界，不降低为逐人录入。

## 算法核查与推进

1. 固定倍率WORLD及按源档案映射均不足以作为当前需求的完成实现。先评估未见输入者的音色转换能力，再投入对应的板端性能优化。
2. 优先审计已有神经候选的源身份划分、推理输入、源校准依赖与目标条件接口，隔离运行与重新验证，不恢复旧持续录放或切PL。交接审阅已指出历史验证集仅2人、旧实时有欠载、目标注册未实现，不能直接宣布采用。
3. 官方LLVC说明以多位输入者与同一目标的合成平行对训练，可作为any-to-one候选；这不等于目标免训练注册。官方Seed-VC提供zero-shot参考音频路线，作为目标注册能力的电脑参考候选；尚未安装或证明7020可实时运行。先审计本地可复用条件，不盲目替换工程或宣称大型模型可上板。
4. 正式评测冻结源说话人独立划分；测试人不得参与源档案拟合或模型调优，转换时仅提供实时输入与目标配置。每人多句、换人、首句、静音后续说分别记录；测试录音只用于评测，不参与该人的校准或适配。开发集与最终留出集分开。
5. 只有离线声音相似度、自然度与内容保持显示有效后，再评估Zynq算力、PL加速与延迟。大小声专项后置；每轮实际录放先问准备。
