# PS-20261025-20：v5 源说话人对抗映射实验

2026-10-27，Remote-PS-C；结果 **REJECTED**。v5 保留 v1 的 PCA96、delta loss 0.25、双向 GRU192、数据切分、seed、优化器、早停和原 strict evaluator，只新增训练期源说话人分类器与梯度反转，权重 0.01，20 个辅助训练说话人；推理只使用映射器输出。源说话人对抗项用于降低中间表示中的源身份信息，不改变目标特征、FARGAN native 或五门口径。

## 训练与控制

复用 200 个经过 SHA 核验的 v1 float16 HuBERT layer9 缓存。辅助训练 192 对/20 人/88733 帧，validation 8 对/2 人/4616 帧只用于选检查点；Fixed-Male4 只做一次开发筛选，Male5 与 Track9 锁定。PCA 与标准化统计和 v1 逐元素相同，PCA 保留方差 0.749045423。v5 映射器参数 1144552，比 v1 多出训练期 speaker head；该 head 不参与推理输出。

最佳 validation step **400**，loss **0.1942023523**；停止 step **1200**，CPU4线程训练 **266.797s**。训练 loss 包含重建、delta 和 speaker cross-entropy；梯度反转只把 speaker 梯度反向传入共享表示。validation checkpoint 选择使用重建+delta损失，不把分类器损失混入验收指标。
