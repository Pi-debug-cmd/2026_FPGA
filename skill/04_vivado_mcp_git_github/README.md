# Vivado MCP and Git Collaboration Skill

This skill helps contributors operate the project's Vivado MCP workflow and publish one traceable task round without disturbing parallel work.

## Contents

- `SKILL.md`: routing instructions and evidence boundaries.
- `references/vivado_mcp.md`: verified MCP calls, session handling, and common Vivado failures.
- `references/git_github.md`: project claim, branch, commit, push, and PR workflow.

## Use

Load `SKILL.md` for Vivado MCP or GitHub work in this repository, then follow only the relevant reference. Commands and paths are examples from the Windows project host; resolve tool locations and work directories on the active machine before running them.
