# 实现与参考的两级门禁比对

## 适用范围
"自研实现 vs 参考模型"的等价性验证：RTL、HLS、C 移植、定点化版本均可。

## 本仓库中的来源
- `sim/check_world_fir.cpp`：参考实现比对
- `sim/generate_pitch_vectors.py`、`generate_ps_vectors.py`、`generate_registered_vectors.py`：测试向量生成
- `report/` 下的实测 JSON：结果留档

## 使用方法（两级门禁）
1. **第一级：解析信号**。用冲激、直流、单频等已知输入验证位宽、符号、对齐、缩放因子。
   这一级不通，后面的比对没有意义。
2. **第二级：真实数据**。用真实音频帧逐样本比对，报告相关系数、最大误差、SNR。
3. **失败分类**：
   - 整体缩放 → 定点小数位或移位方向错
   - 单 bin / 单点偏移 → 地址或时序差一拍
   - 周期性缺块 → 缓冲或握手丢数据

## 判据示例
- 解析级：逐样本完全一致
- 真实级：corr ≥ 0.999 且 max error ≤ 若干 LSB（按位宽定）

## 失效条件
- 参考实现本身未经验证时，比对只能证明"一致"，不能证明"正确"

## 复用场景
任何"实现 vs 参考"的等价性验收；换题目只改向量生成与判据阈值。
