# 野火 Zynq-7020 板载资料

本目录保存野火皓月开发板的**厂商原始参考资料**，供核对硬件、音频接口和部署条件。当前项目的代码、进度和测试结论仍以仓库其他目录为准。

| 文件 | 用途 |
| --- | --- |
| `[野火]皓月_开发板硬件规格书V1.2.pdf` | 核对器件、DDR、接口及板卡规格 |
| `EBF410020V1R2_SCH_20250307.pdf` | 核心板原理图，核对 Zynq 与 DDR 等连线 |
| `EBF410021_SCH_20230925.pdf` | 底板原理图，核对 WM8960 及音频接口 |
| `皓月ZYNQ开发板引脚映射表.xls` | 核对 PL 引脚与外设连接 |
| `ZYNQ皓月开发板快速测试手册20260608.pdf` | 核对启动、接线和基础测试方法 |
| `vivado_prj_zynq7020.zip` | 野火厂商的 Vivado 参考工程，含硬件设计、约束等；**不是本项目目前运行的最终工程** |

本项目按野火皓月 Zynq-7020 开发，工程资料采用 `xc7z020clg400-2`，PS 端 DDR 为 1GB。音频使用板载 WM8960；外接麦克风接粉色输入口，音箱音频插头接绿色输出口。历史音频链路曾使用 32kHz、S24_LE、双声道，算法实验常用 16kHz、单声道；接入模型时必须核对并处理格式转换，不能直接假定二者相同。

**给接手 AI 的要求：**仓库中的既有目标人物录音可用于开发、训练和离线评测，但不能替代正式演示时的板上目标声源注册。现行验收要求以根目录 `AGENTS.md` 和 `project_guide.md` 为准：演示现场在板上录制目标人物语音并在板上构建转换配置；未经预先录入的陌生测试者随后直接讲话，板卡低延迟输出同一目标音色。准备和实时运行都不能依赖另一台电脑或云端。设计模型时要核算 7020 上的内存、PS 运算量、PL 资源、数据搬运和延迟。没有连接实物板卡时，可以做离线训练、评测和部署准备，但不能把电脑上的效果或速度写成“已在板上通过”。

接手前按 `AGENTS.md` 指定顺序阅读 `project_guide.md`、最新 `handoff_*.md` 和 `coummucation.md`，再查 `team_project/project_status.md` 与 `board/hardware_inventory.md`。本文件只说明厂商资料和硬件事实，不覆盖根目录的需求、验收顺序或协作规则。
